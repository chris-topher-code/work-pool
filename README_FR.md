# TaskSite - Plateforme de Distribution de Tâches

Connectez créateurs de projets et prestataires. Publiez, collaborez, réalisez.

## Fonctionnalités

- 🔐 Inscription et connexion
- 📝 Publier des projets (Demandeur) / Postuler (Prestataire)
- 📊 Statuts : Ouvert → En cours → Terminé
- 💬 Commentaires et mur de messages
- ⭐ Évaluations entre utilisateurs
- 👤 Profils avec historique de projets
- 💰 Paiement QR code (WeChat / Alipay)
- 🌐 Français / English / 中文
- 📱 Design responsive + outil d'aperçu mobile
