# TaskSite - Connect & Collaborate

A programming task distribution platform. Post projects, find collaborators, and get things done.

## Features

- 🔐 User registration & login
- 📝 Post projects (Requester) / Apply for projects (Receiver)
- 📊 Project status: Open → In Progress → Completed
- 💬 Comments & message wall
- ⭐ Reviews & ratings between users
- 👤 User profiles with project history
- 💰 QR code payment (WeChat / Alipay)
- 🌐 English / 中文 / Français
- 📱 Mobile responsive + preview tool
